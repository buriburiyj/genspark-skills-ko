# Fix Error

## Rules
1. Explain the cause in one line.
2. Show only the changed code (file name + location + changed lines). Never rewrite the whole file.
3. If you are not sure, do not guess. Give one way to check instead.
4. If the same error is not fixed after two attempts, stop and suggest a different approach.
5. Keep explanations short.
