# 대화 정리 (Conversation Handoff Summary)

긴 작업을 하다 보면 대화가 길어져 컨텍스트가 부족해진다. 이 스킬은 **지금까지의 대화를 새 대화에서 바로 이어받을 수 있는 인수인계 요약**으로 압축한다.

핵심 가치는 "다음 대화의 나(또는 다른 세션)가 이 요약만 읽고 바로 작업을 재개할 수 있는가"이다. 그래서 대화를 그대로 줄여 쓰는 게 아니라, **다음 작업에 필요한 정보만 골라 남기는** 방식으로 쓴다.

## 언제 쓰는가

사용자가 아래처럼 말할 때:

- "대화 정리해줘" / "대화 정리"
- "인수인계 요약 만들어줘", "작업 넘겨줄 요약"
- "새 대화로 옮길 수 있게 정리해줘", "새 세션에서 이어서 하려면"
- "지금까지 한 거 요약해줘", "컨텍스트 정리해줘"

또는 사용자가 명시적으로 요청하지 않아도, 한 작업이 여러 턴에 걸쳐 진행되어 컨텍스트가 길어졌고 사용자가 새 대화로 넘어가려는 정황이 보이면 먼저 제안한다.

## 출력 규칙

1. **아래 고정 형식을 그대로** 쓴다. 섹션 제목을 바꾸거나 새 섹션을 추가하지 않는다. 대괄호까지 그대로 유지한다.
2. **인사말·설명·서론·맺음말 없이 요약만** 출력한다. "다음은 요약입니다", "도움이 되셨길 바랍니다" 같은 문장은 넣지 않는다.
3. **짧게** 쓴다. 각 항목은 한 줄에서 몇 줄. 대화 내용을 복사하지 말고 압축한다. 정보가 많아도 늘리지 말고 골라낸다.
4. **대화에 없는 내용을 지어내지 않는다.** 해당 정보가 대화에 없으면 그 항목에 `(대화에 없음)`이라고 쓴다. 추측해서 채우지 않는다.
5. **마지막 줄**에 정확히 다음 문장을 넣는다:
   `새 대화에 이 내용을 붙여넣으세요`
6. 코드는 `[핵심 코드]` 섹션에만, **꼭 필요한 조각만** 발췌한다. 파일 전체를 붙이지 않는다. 코드가 없으면 `(없음)`.
7. 기본은 일반 텍스트로 출력한다. 사용자가 "복사하기 쉽게"라고 하면 전체를 하나의 코드블록으로 감싼다.

## 출력 형식

```
[프로젝트 목표]

[사용 언어/도구]

[파일 구조와 각 파일 역할]

[완성된 것]

[남은 할 일] (중요한 순서대로)

[지금 있는 오류나 문제]

[내가 정한 규칙이나 스타일]

[핵심 코드] (전체 코드 말고 꼭 필요한 부분만)

새 대화에 이 내용을 붙여넣으세요
```

## 각 섹션에 무엇을 쓰는가

- **`[프로젝트 목표]`** — 사용자가 최종적으로 이루려는 것. 한두 줄.
- **`[사용 언어/도구]`** — 언어·프레임워크·라이브러리, 실행/빌드 명령, 함께 쓴 도구나 스킬 이름.
- **`[파일 구조와 각 파일 역할]`** — 파일 트리와 각 파일이 하는 일을 한 줄씩. 경로는 백틱으로 감싼다. 아직 파일이 없으면 `(없음)`.
- **`[완성된 것]`** — 이미 동작하거나 끝난 것만. 진행 중인 것은 여기 넣지 않는다.
- **`[남은 할 일]`** — 사용자가 말한 우선순위 순서대로. 다음 대화에서 곧바로 착수할 수 있게 구체적으로 쓴다.
- **`[지금 있는 오류나 문제]`** — 에러 메시지, 재현 조건, 아직 안 풀린 문제. 없으면 `없음`.
- **`[내가 정한 규칙이나 스타일]`** — 사용자가 지시한 규칙, 코딩/문서 스타일, 금지사항, 선호 표현.
- **`[핵심 코드]`** — 다음 대화에서 필요한 최소한의 코드 조각(함수, 설정, 명령). 긴 코드는 시그니처와 핵심 줄만 남긴다.

## 예시

대화: 파이썬으로 CSV 매출 파일을 읽어 월별 합계를 내는 스크립트를 만들던 중, 마지막 열 이름이 달라서 KeyError가 났고 아직 못 고친 상태.

출력:

```
[프로젝트 목표]
매출 CSV를 읽어 월별 합계를 계산하는 파이썬 스크립트 완성

[사용 언어/도구]
Python 3.11, pandas. 실행: `python3 sales.py data.csv`

[파일 구조와 각 파일 역할]
- `sales.py` — CSV 로드 후 월별 집계
- `data.csv` — 매출 원본 (열: date, amount, region)

[완성된 것]
- CSV 로드 및 날짜 파싱
- 월별 합계 계산 함수

[남은 할 일] (중요한 순서대로)
1. 열 이름 불일치(KeyError) 수정
2. 지역별 소계 추가
3. 결과를 CSV로 저장

[지금 있는 오류나 문제]
`KeyError: 'amount'` — 원본 CSV의 실제 열 이름은 `sales_amount`

[내가 정한 규칙이나 스타일]
- 결과는 한국어로 출력
- 파일 경로는 절대경로 금지, 인자로 받기

[핵심 코드] (전체 코드 말고 꼭 필요한 부분만)
def monthly_total(df): return df.groupby(df["date"].dt.to_period("M"))["sales_amount"].sum()

새 대화에 이 내용을 붙여넣으세요
```
