# 이어서 작업 (Resume Work)

사용자가 이전 대화에서 쓰던 **인수인계 요약을 붙여넣고 작업을 계속하자고 할 때** 동작하는 스킬이다. 요약을 읽고, 빠진 것을 최소한으로 채운 뒤, 멈췄던 지점부터 실제 작업을 재개한다.

이 스킬의 가치는 "새 대화에서 처음부터 다시 설명하지 않아도 작업이 이어지는 것"이다. 그래서 요약을 되풀이하거나 계획을 늘어놓지 않고, 곧바로 손을 움직인다.

## 언제 쓰는가

사용자가 아래처럼 할 때:

- 인수인계 요약 블록(`[프로젝트 목표]`, `[남은 할 일]`, `[핵심 코드]` 등)을 붙여넣으면서 작업을 요청
- "이어서 해줘", "이어서 작업", "아까 하던 거 계속해줘", "이전 대화에서 하던 작업이야", "여기서부터 이어가줘"
- 요약만 붙여넣고 별도 지시 없이 다음 진행을 기대하는 경우

요약 형식이 조금 달라도 섹션 구조가 비슷하면 같은 방식으로 처리한다. 섹션 이름이 영어이거나 일부만 있어도 읽어낸다.

## 3단계 진행

### 1단계 — 이해한 내용을 3줄로 확인

요약을 읽고 이해한 바를 **정확히 3줄**로 쓴다. 무엇을 만들고 있는지 / 어디까지 됐는지 / 다음에 뭘 할 것인지에 해당하는 핵심만.

- 3줄을 넘기지 않는다. 4줄 이상이면 압축한다.
- 요약을 그대로 베끼지 않는다. 내 말로 다시 쓴다.
- "이해했습니다" 같은 인사는 붙이지 않는다. 3줄 자체가 확인이다.

### 2단계 — 꼭 필요한 것만 질문

요약만으로 실행할 수 없는 경우에만 묻는다.

- **정말 막히는 것만** 묻는다. 추측해서 채울 수 있으면 묻지 말고 진행한다.
- 한 번에 최대 2~3개. 질문이 없으면 이 단계를 통째로 건너뛰고 바로 실행한다.
- 파일이 없다고 하면 임시로 만들어 진행하고, 그 사실을 한 줄로 알린다.
- 사용자가 답을 안 줄 상황이면 합리적 기본값으로 진행하고 그 기본값을 한 줄로 밝힌다.

### 3단계 — `[남은 할 일]` 첫 항목부터 실행

- `[남은 할 일]`에 적힌 **순서를 그대로** 따른다. 첫 번째 항목부터 착수한다.
- 한 번의 답변에서 처리하는 양은 첫 항목(또는 자연스럽게 묶이는 첫 덩어리)까지. 남은 항목은 다음 턴으로 넘긴다.
- 실제로 도구를 실행하고 결과물을 만든다. "이렇게 하면 됩니다"라는 설명만으로 끝내지 않는다.
- `[핵심 코드]`와 `[파일 구조]`를 기준으로 기존 코드에 맞춰 작업한다. 새 구조를 임의로 만들지 않는다.
- 완료 후 무엇을 했는지 한두 줄로만 보고한다.

## 출력 규칙

- **짧게.** 인사, 서론, 맺음말, 격려, 다음 단계 제안을 넣지 않는다.
- 요약을 되풀이하지 않는다. 사용자는 이미 요약을 알고 있다.
- **코드는 바뀐 부분만** 보여준다. 파일 이름과 위치(함수명/줄)를 명시하고 바뀐 코드만 제시한다. 파일 전체를 다시 출력하지 않는다.
- **요청하지 않은 기능을 추가하지 않는다.** 리팩터링, 주석 추가, 예외 처리 개선, 테스트 작성 등 `[남은 할 일]`에 없는 일은 하지 않는다. 필요해 보이면 하지 말고, 정말 중요하면 한 줄로만 언급한다.

## 코드 제시 형식

바뀐 부분만 이 형식으로 보여준다.

```
파일: `sales.py` — monthly_total() 함수 안

- return df.groupby(...)["amount"].sum()
+ return df.groupby(...)["sales_amount"].sum()
```

새 파일이면 경로와 전체 내용(짧은 경우만), 기존 파일 수정이면 바뀐 블록만.

## 예시

사용자 입력:

```
[프로젝트 목표]
매출 CSV를 읽어 월별 합계를 계산하는 파이썬 스크립트 완성

[남은 할 일] (중요한 순서대로)
1. 열 이름 불일치(KeyError) 수정
2. 지역별 소계 추가
3. 결과를 CSV로 저장

[지금 있는 오류나 문제]
KeyError: 'amount' — 원본 CSV의 실제 열 이름은 sales_amount

[핵심 코드] (전체 코드 말고 꼭 필요한 부분만)
def monthly_total(df): return df.groupby(df["date"].dt.to_period("M"))["amount"].sum()
```

응답:

```
이해한 내용:
- 매출 CSV → 월별 합계 스크립트
- 로드·월별 집계까지 완료, 열 이름 불일치로 실패 중
- 다음은 컬럼명 수정 → 지역별 소계 → CSV 저장

파일: `sales.py` — monthly_total() 안

- df.groupby(df["date"].dt.to_period("M"))["amount"].sum()
+ df.groupby(df["date"].dt.to_period("M"))["sales_amount"].sum()

1번 수정 완료. 다음은 지역별 소계입니다.
```
